# 0002 Build Daily Backtest Engine

来源：`docs/0006-backtest-center/design.md`、`docs/0006-backtest-center/progress.md`

## 目标

接入 Hikyuu A 股日频回测执行，按[实施计划](./hikyuu-implementation-plan.md)把已版本化的行情、股票池、策略信号和交易约束交给同一引擎，并映射回测结果。

## 前置依赖

- 回测数据模型已完成。
- 策略预览、组合目标持仓和已验收的 Hikyuu 历史行情快照可用。

## 执行步骤

1. 创建任务时锁定 Hikyuu 版本、导入批次/摘要、复权口径、股票池和策略版本。
2. 验证回测区间内行情、基准和约束数据完整；缺失关键数据时拒绝正式运行。
3. 每个交易日仅向策略暴露当日及以前已发布数据；收盘生成信号，次日开盘执行。
4. 映射策略信号与目标仓位到 Hikyuu 执行组件，统一检查 A 股交易约束。
5. 从 Hikyuu 账户与成交记录映射现金、持仓、净值、拒单原因和日志。

## 产出

- Hikyuu 日频回测适配层。
- Hikyuu 账户结果到平台报告的映射。
- 每日状态记录。

## 验收

- 可以使用小样本跑完整个回测循环。
- 回测过程中不能读取未来日期数据。
- 重复运行同一配置结果一致。
